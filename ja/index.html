Mosquito Simulator: Bite & Run

Mosquito Simulator: Bite & Run（App Storeでの日本語名：モスキート：蚊のいたずらシミュレーター）は、プレイヤーが蚊になって遊ぶ無料のiPhoneゲームです。虫サイズの視点でリアルな20の部屋を飛び回り、眠っている人にとまって「黄金の瞬間」まで血を吸い、スローモーションで平手打ちをかわして、夜明け前に窓から脱出します。App Storeでは2026年11月9日に配信が始まりました。

ゲーム本体はまだ日本語に対応していません（英語・スペイン語・フランス語・ドイツ語・トルコ語・アラビア語）。

1回の夜では何をするの？

1つの夜は、1つの部屋と1つの目標でできています。窓が開くだけの血を吸い、夜明け前に外へ出ること。1夜はたいてい数分で終わります。

  1. 忍び込む。長押しで飛び、ドラッグで向きを変えます。明かりや開いた目には近づかないようにしましょう。
  2. 肌を探す。眠る人の温かい息の流れに乗りましょう。肌まで導いてくれるうえ、早くお腹が満たされます。
  3. 刺す。BITE（刺す）ボタンを長押しし、リングが赤くなる直前に指を離します。金色に光った瞬間に離せばパーフェクトな一刺しです。
  4. 脱出する。お腹がいっぱいになると体が重く、遅くなります。平手打ちをかわし、開いた窓から飛び出しましょう。

ほかの蚊のゲームとどこが違うの？

スマホの蚊ゲームの多くは、短いアーケード型の繰り返しです。本作はステルスゲームで、毎晩のプレイを形づくる5つのシステムを中心に作られています。

  • 息の流れ（ブレスプルーム）：眠る人は目に見える温かい息を吐きます。その中を飛ぶと匂いをロックでき、本物の蚊が吐く息のCO₂をたどるのと同じように肌へ向かえます。
  • 血の重さ：吸うたびに体が重く遅くなり、窓までの帰り道が厳しくなります。
  • スラップタイム：手が振り下ろされると時間がゆっくりになります。ぎりぎりでダッシュしてかわすと、その場面をクリップとして保存してくれます。
  • ライブの羽音ミュージック：BGMはありません。シンセがあなたの飛び方を音にし、部屋に気づかれ始めると暗い響きに変わります。
  • 実在の蚊：イエカからオオカ属（Toxorhynchites）まで実在する10種の蚊が登場し、それぞれ生態にもとづいたボーナスを持っています。

購入したアイテムが届かない

ゲーム内のSettings（設定）を開き、Restore purchases（購入を復元）をタップしてください。消費しないアイテム、No Ads（広告なし）、Mosquito Clubは、同じApple Accountでサインインしているどの端末でも復元されます。Blood（血）のパックなどの消費型アイテムは復元できません。

Mosquito Clubを解約する

iPhoneの設定 → ユーザー名 → サブスクリプション → Mosquito。更新日の少なくとも24時間前までに解約してください。

返金

返金はAppleが対応します：reportaproblem.apple.com。

データを削除したい

返信を受け取りたいメールアドレスから、件名を「Delete my data」とし、ゲーム内のProfile（プロフィール）に表示されているPlayer IDを書いて送ってください。クラウドセーブとプロフィールを30日以内に削除します。
